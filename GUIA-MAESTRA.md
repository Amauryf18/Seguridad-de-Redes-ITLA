# Guía maestra de los tres repositorios

Debes crear **3 repositorios independientes**, uno por infraestructura.

## Repositorios

1. `Infraestructura-1-FortiGate-S2S`
2. `Infraestructura-2-FortiGate-Cisco-S2S`
3. `Infraestructura-3-Remote-Access-FortiClient`

## Regla importante

No mezclar evidencias, videos, running-configs ni scripts entre repositorios.

Cada repositorio debe poder entenderse por sí solo.

## Orden del README

1. Video
2. Propósito
3. Topología
4. Documentación
5. Evidencias
6. Scripts
7. Running-configs

## Entrega final

Crear tres archivos TXT siguiendo exactamente:

`<Nombre>_<Matrícula>_P1.txt`

Sustituir P1 por el identificador que corresponda si el docente utiliza otro número para cada infraestructura.

## Seguridad

Nunca subir:
- Contraseñas reales.
- Pre-shared keys reales.
- Tokens.
- Certificados privados.
- Credenciales personales.

Reemplazarlos por `[REDACTED]`.
